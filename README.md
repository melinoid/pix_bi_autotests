## Проект с автотестами для PIX BI

Статья в работе.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   ```
2. Установите зависимости:
   ```bash
   npm i && npx playwright install --with-deps
   ```
3. Создайте **.env** файл со следующими переменными
   ```bash
   WORKERS_COUNT=<количество воркеров>

   BI_URL="полный адрес стенда определённой версии: https://dev32.pixbi.ru"
   BI_USERNAME="имя пользователя на стенде"
   BI_PASSWORD="пароль пользователя на стенде"
   BI_USER_ID="идентификатор пользователя на стенде"

   AD_USERNAME="имя пользователя для подключения к AD"
   AD_PASSWORD="пароль для подключения к AD"
   AD_HOST="AD адрес"
   AD_PORT="AD порт"
   AD_DOMEN="AD домен"
   ```

## Запуск тестов (из корня проекта)
### Запуск всех доступных тестов:
   ```bash
   npx playwright test
   ```
### Запуск UI тестов во всех браузерах:
   ```bash
   npx playwright test -g "Smoke"
   ```
### Запуск UI тестов в определённом браузере:
   ```bash
   npx playwright test --project="Smoke 1.32 Chromium"
   ```
   ```bash
   npx playwright test --project="Smoke 1.32 Firefox"
   ```
   ```bash
   npx playwright test --project="Smoke 1.32 Edge"
   ```
### Запуск всех API тестов:
   ```bash
   npx playwright test --project="API Scripts 32"
   ```
### Запуск тестов в контейнере (необходим установленный docker):
    ```bash
    docker compose up
    ```

## Важно

* Автотесты можно запускать в многопоточном режиме (при значении переменной WORKERS_COUNT > 1). При этом для каждого воркера создаётся отдельный пользователь, под которым выполняются тесты (Большое кол-во пользователей съедает pro лицензии, т.к. на каждый прогон создаются новые уникальные пользователи с назначением лицензиямй и дальнейшим удалением).
* В случае, если данные не были удалены во время прохождения тестов, они удаляются через api после завершения тестов.
* В API наборе временно собраны прикладные запросы.
